# Розширена система користувачів UEBSchool

## 🎉 Що додано:

### 1. **Фото профілю**
- Завантаження та зміна фото профілю
- Зберігання в Firebase Storage
- Автоматичне стиснення та оптимізація
- Лімі т розміру: 5MB

### 2. **Унікальний User ID**
- Формат: `UEB-00001`, `UEB-00002`, і т.д.
- Автоматична генерація при реєстрації
- Збережено лічильник у Firebase Realtime Database
- Відображається в кабінеті

### 3. **Система повідомлень**
- Повідомлення від адміністратора
- 4 типи: інфо, успіх, попередження, завдання
- Позначка "прочитано/непрочитано"
- Відображення непрочитаних з індикатором

### 4. **Домашні завдання**
- Створення завдань адміністратором
- Назва, опис, термін здачі
- Додавання файлів (посилання)
- Позначка виконання
- Автоматичне повідомлення про нове завдання

### 5. **Адмін панель**
- Відправка повідомлень користувачам
- Створення домашніх завдань
- Вибір конкретних користувачів або всіх
- Перегляд списку користувачів

## 🔧 Налаштування Firebase:

### 1. Увімкніть Firebase Storage:

```bash
1. Firebase Console → Storage
2. Get Started
3. Start in test mode (для розробки)
4. Виберіть локацію
```

### 2. Правила безпеки для Storage:

```javascript
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /profile-photos/{userId}/{allPaths=**} {
      allow read: if true;
      allow write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
```

### 3. Правила безпеки для Realtime Database:

```json
{
  "rules": {
    "users": {
      "$uid": {
        ".read": "$uid === auth.uid || root.child('admins').child(auth.uid).val() === true",
        ".write": "$uid === auth.uid || root.child('admins').child(auth.uid).val() === true"
      }
    },
    "counters": {
      ".read": true,
      ".write": "auth != null"
    },
    "admins": {
      ".read": "auth != null",
      ".write": false
    }
  }
}
```

### 4. Додайте адміністратора вручну:

В Firebase Console → Realtime Database:

```json
{
  "admins": {
    "UID_ВАШОГО_КОРИСТУВАЧА": true
  },
  "counters": {
    "userIdCounter": 0
  }
}
```

Замініть `UID_ВАШОГО_КОРИСТУВАЧА` на UID вашого акаунта з Firebase Auth.

## 🚀 Використання:

### Для користувачів:

1. **Зміна фото**: Кабінет → вкладка "Профіль" → клік на камеру
2. **Повідомлення**: Кабінет → вкладка "Повідомлення"
3. **Домашнє завдання**: Кабінет → вкладка "Домашнє завдання"

### Для адміністраторів:

1. Перейдіть на `/admin/notifications`
2. Виберіть тип (Повідомлення або Домашнє завдання)
3. Заповніть форму
4. Виберіть користувачів
5. Відправте

## 🐛 Troubleshooting:

**Помилка завантаження фото:**
- Перевірте правила Storage
- Перевірте розмір файлу (<5MB)
- Перевірте формат (jpg, png, gif, webp)

**Не відображається адмін панель:**
- Перевірте наявність вашого UID в `/admins`
- Перевірте правила Database
- Очистіть кеш браузера

**User ID не генерується:**
- Перевірте наявність `/counters/userIdCounter` в Database
- Перевірте права на запис
