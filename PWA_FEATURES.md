# PWA Features

## ✅ Implemented Features

### 1. **Progressive Web App (PWA)**
- Installable on mobile and desktop devices
- Works offline with service worker caching
- Fast loading with optimized assets
- Native app-like experience

### 2. **Web App Manifest**
- Custom app name and icons
- Theme color: Blue (#3b82f6)
- Standalone display mode
- Portrait orientation support
- Ukrainian language support

### 3. **SEO Optimization**
- **Sitemap** (`/sitemap.xml`) - Automatically generated with all main pages
- **Robots.txt** (`/robots.txt`) - Configured for search engine crawling
- Open Graph meta tags for social sharing
- Twitter Card support
- Structured metadata

### 4. **PWA Icons**
Generated icons in multiple sizes:
- `icon-192.png` - 192x192 (standard PWA)
- `icon-512.png` - 512x512 (high-res PWA)
- `apple-touch-icon.png` - 180x180 (iOS devices)
- `favicon.ico` - 32x32 (browser tab)

### 5. **Install Prompt**
- Custom install banner on mobile
- User-friendly installation flow
- Remembers user's dismissal choice
- Smooth animations

## 🚀 How to Use

### Testing PWA Locally
```bash
npm run build
npm start
```
Then visit `http://localhost:3000` in Chrome/Edge and check the install prompt.

### Installing the App
1. Visit the website on mobile or desktop
2. Look for the install prompt banner
3. Click "Встановити" (Install)
4. App will be added to your home screen/app drawer

### Checking PWA Score
1. Open Chrome DevTools
2. Go to "Lighthouse" tab
3. Select "Progressive Web App" category
4. Click "Generate report"

## 🔧 Technical Details

### Service Worker
- Automatically generated by `@ducanh2912/next-pwa`
- Disabled in development mode
- Caches static assets and pages
- Updates automatically

### Caching Strategy
- Static assets: Cache-first
- API routes: Network-first
- Pages: StaleWhileRevalidate

### Files Generated
- `/public/sw.js` - Service worker script
- `/public/workbox-*.js` - Workbox runtime
- All excluded from git (see `.gitignore`)
