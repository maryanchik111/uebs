# Налаштування відправки повідомлень та Д/З студентам

## Додайте змінні оточення

У файлі `.env.local` додайте:

```env
# Admin Key для авторизації API
ADMIN_KEY=your-secure-admin-key-here
NEXT_PUBLIC_ADMIN_KEY=your-secure-admin-key-here

# SMTP налаштування (якщо ще не налаштовано)
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_SECURE=false
SMTP_USER=your-email@gmail.com
SMTP_PASSWORD=your-app-password
SMTP_FROM=your-email@gmail.com
```

## Функціональність

### Відправка повідомлень
- Виберіть студентів (один або декілька, або всіх)
- Натисніть кнопку "Повідомлення"
- Заповніть форму з заголовком, текстом повідомлення та типом
- Повідомлення буде відправлено:
  - На email студента
  - В особистий кабінет (якщо студент зареєстрований з такою ж поштою)

### Відправка домашнього завдання
- Виберіть студентів
- Натисніть кнопку "Д/З"
- Заповніть форму з назвою, описом, терміном здачі та посиланням на файл
- Домашнє завдання буде відправлено:
  - На email студента
  - В особистий кабінет в розділ "Домашнє завдання"

## API Endpoints

### POST /api/students/send-notification
Відправка повідомлення студентам

### POST /api/students/send-homework
Відправка домашнього завдання студентам
